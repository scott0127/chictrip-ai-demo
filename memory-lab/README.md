# Memory Lab — isolated experience test

Standalone experiment; the existing memory-atlas and other pages are unchanged. Open index.html locally or serve this folder. Native HTML/CSS/JS, no network dependencies for the experience.

- One Osaka memory, three clearly simulated crops/perspectives, two interactive memory objects, photo/AI poetry toggle, optional subtle planar tilt.
- User-selected images are local object URLs only, never uploaded. Per-view images clear on refresh. AI toggle is disabled for these images to avoid pretending to generate a matching illustration.
- Only visited memory-object IDs persist locally. Dialogs support Escape, focus return, keyboard focus, and reduced motion.
- This does not implement real depth segmentation, real shared albums, live AI generation, or recorded personal memories.
