# 景點實景照片與授權

本 Demo 的 15 個旅程節點各有對應實景照片。照片僅供辨識景點與展示介面，不代表即時現況、旅遊日期、當日天氣或人潮；場景可能與模擬行程季節不同。

素材取自 Wikimedia Commons 的公開檔案頁及其提供的縮圖。已保留所下載圖片原樣，僅於網頁以 CSS object-fit / object-position 調整顯示範圍；未以生成式 AI 製作或修改照片。圖片隨離線分享包提供，顯示時不需要連線。

保留以下作者署名、來源及各照片授權。照片授權不改變其他程式碼或素材的授權。
