# 圈選＋偏好排程原型

直接開啟 index.html 即可離線使用，分享時請傳整個資料夾或 ZIP。

1. 在地圖按住畫出封閉範圍；也可按快捷區域，或使用「逐點選擇」。
2. 輸入偏好，例如「喜歡老街和甜點，不要太趕，下午想喝咖啡」。
3. 生成草案，查看地圖順序與停留理由；修改偏好後重新安排。
4. 套用到第 1 天；已套用行程儲存在該瀏覽器 localStorage。

## 原型範圍

- 原生 HTML/CSS/JS，無 CDN、登入、金鑰或外部 AI 呼叫。
- 圈選採點在多邊形內判斷，範圍會實際影響候選景點。
- 自然語言採有限關鍵字規則模擬，支援老街、甜點、咖啡、室內、購物、景觀、悠閒/充實。非完整語意理解；其他需求會提示示範限制。
- 地理座標和底圖使用原專案離線資料，景點照片沿用原專案來源。參考 assets/MAP-LICENSE.md 和 PHOTO-LICENSE.md。
- 景點分類、停留時間、交通時間、可安排時段皆為 Mock；路線僅表示景點順序，非導航。餐飲為待選的休息時段，未假設真實店家有營業。
- 僅展示圈選與偏好排程，未接入正式 chicTrip 帳戶或後端。
